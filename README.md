## 🚀 Local Setup & Deployment

### Prerequisites
* [Node.js](https://nodejs.org/) (v16.x or higher)

### Setup Steps
1. **Clone the repository**:
   ```bash
   git clone https://github.com/nohitha08-cloud/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open your browser at 👉 **`http://localhost:5173/`**

4. **Build for production**:
   ```bash
   npm run build
   ```
   The production-ready output bundle will be created in the `/dist` directory.
